# 财报 PDF 全文解析与证据页检索

项目四的公共接口位于 `powercontext.sources.pdf_pages`，与其他赛题实现共同维护在 `feature/all-solutions` 分支。

解析器使用评测环境提供的 pypdf 读取全部物理页，包括空白页。Source 捕获原始页输入，以文档 ID、完整字节摘要和物理页码确定稳定身份，并提供标准文本投影。支持空密码权限标记；无法完整解析时抛出 ValueError，不返回部分页。

检索只读取调用方提供的 scoped Memory 当前快照，返回已有条目的精确 citation，不创建旁路引用。先从问题与文档标识中识别公司名称（含字母数字混合名称），防止其他报告挤占候选位置。比较问题保留同一公司的多个年度报告。随后融合正文 BM25、通用财务概念和章节标题的检索排序，使底层财务报表能与讨论文字一起进入候选结果。公司名称、年份与正文主题分开处理。实现不依赖文档或问题清单，不读取答案、证据标注或评测资产，不使用模型或网络服务。

索引在每次请求内建立，不跨 scope、重启或 Memory 修订缓存引用；成本随范围内正文词项数线性增长。真实 Runtime 的来源捕获、持久化和引用回查使用原有公共接口。

回归测试包含两个在旧实现上可复现的遗漏：其他公司页面挤掉目标公司的证据，以及 EBITDA 问题只召回讨论文字、遗漏底层利润表或现金流量表。另检查空密码、密码保护、修订、序列化、去重、上限、快照变化和范围隔离。

本地验证使用 Windows、Python 3.12 和 pypdf 6.19.0，未等同于官方 Linux 完整固定依赖环境。公开 503 页财报的 6 项验收和 9 项产品测试通过。公开验收不分发质量 gold，不能据此保证隐藏集 Recall@20、解析质量门槛或最终得分。

官方环境运行：

```sh
make -C competition install
make -C competition test-pdf
```
